  ## Introduction 

This project demonstrates how to build a dynamic music application using React. The purpose of this assignment was to practice creating and managing components, handling state, and passing data between components using props. The application allows users to view a list of albums, select an album to see its tracks, lyrics, and video, and also create or edit albums. This project helped strengthen my understanding of how React updates the user interface based on changes in state and how multiple components work together to create an interactive application.

## Troubleshooting

| Issue | Solution |
|--|--|
| npm start error (package.json not found) | Navigate to the correct project folder before running npm start |
| Module not found errors | Check import paths and file names for correct spelling and casing |
| Component not rendering (invalid element type) | Ensure each component uses export default and imports are correct |
| Blank page in browser | Check terminal and browser console for errors and fix them |
| File name capitalization issues | Rename file properly (example: NewAlbum.js) and update imports |
